# NoctCent (MoonCat) - versi website

Semua file ada di satu level (tanpa subfolder) supaya gampang diupload dari HP.

## Pasang di GitHub Pages (dari HP)
1. Buat repo baru di GitHub (public).
2. Di repo: Add file > Upload files, lalu pilih SEMUA file hasil ekstrak zip (bisa pilih banyak sekaligus). `index.html` harus ada di paling luar.
3. Commit changes.
4. Settings > Pages > Source "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
5. Tunggu 1-2 menit, buka `https://USERNAME.github.io/NAMA-REPO/`.

## Catatan
- Data tersimpan di browser (localStorage), per perangkat.
- Notifikasi, widget, dan share sheet native hanya jalan di app Expo, di web otomatis dilewati.
